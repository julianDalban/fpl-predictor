# FPL Player Points Predictor
## CS-UY 4563 - Intro to Machine Learning

The goal of this project is to be able to predict the total_points of a Fantasy Premier League player for an upcoming gameweek using only information available before that gameweek starts.

To set-up the data, please run the necessary scripts.


## Data

Raw data is downloaded from github.com/vaastav/Fantasy-Premier-League for seasons 21/22, 22/23, and 23/24. Run the necessary scripts to reproduce it.
